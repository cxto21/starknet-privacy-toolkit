# 0001: Oz Kit Flow Alignment and Repository Hardening

Status: Proposed
Date: 2025-12-03

## Context

This fork included installation elements inspired by the flow from [Oz Kit](https://github.com/naiam-studio/Oz-Kit-Ztarknet-Noir-Garaga), adding scripts that primarily focus on dependency installation to increase the likelihood of a reproducible scenario Noir → Barretenberg → Garaga → Cairo.

## Decision

- Restore and follow the original flow from Step 2 in `BADGE_SETUP.md` and explicitly resume from Step 4 (Starknet Foundry).
- Limit scripts to “dependency installation” by adding a Makefile and manual implementation documentation.
- Use repository-relative paths and dynamic binary detection (e.g., `garaga` from venv or PATH).
- Normalize/pin versions across the repository, mainly: `nargo 1.0.0-beta.1`, `bb 0.67.0`, `scarb 2.9.2`, `sncast 0.53.0`, `garaga 0.15.5`.

## Implementation

- Documentation
  - `README.md`: repo-relative paths; how to start the API with `bun run api`.
  - `DEPENDENCIES.md`: "deps-only" scope and verification/uninstall.

- Scripts and Makefile
  - Idempotent installers: `install-noir.sh`, `install-scarb.sh`, `install-barretenberg.sh` (fallback to `bbup`), `install-sncast.sh`.
  - `setup.sh` (deps-only) and `uninstall.sh` (cleanup and summary) + `verify.sh` (structure and coherence).
  - Makefile with `install-all` and Oz Kit tasks (accounts and utilities).

- API and ZK pipeline
  - `api/server.ts`: repo-relative paths; detect `garaga` in venv or PATH; writes `Prover.toml`; runs `nargo` → `bb` → `garaga`; responds `{ calldata, commitment }`.
  - `package.json`: `api` script to start the server.

- Cairo Verifier
  - `donation_badge_verifier/src/lib.cairo`: entry module to compile with `scarb build`.

- Artifacts
  - `calldata.txt`: output generated by Garaga (optionally versioned for reproducibility).

## Verification Checklist

```bash
./scripts/verify.sh
make install-all
cd donation_badge_verifier && scarb build && cd -
cd zk-badges/donation_badge && nargo execute witness \
  && bb prove_ultra_keccak_honk -b ./target/donation_badge.json -w ./target/witness.gz -o ./target/proof \
  && bb write_vk_ultra_keccak_honk -b ./target/donation_badge.json -o ./target/vk && cd ../..
garaga calldata --system ultra_keccak_honk --vk zk-badges/donation_badge/target/vk --proof zk-badges/donation_badge/target/proof --format array > calldata.txt
bun run api &
curl -s -H 'Content-Type: application/json' -d '{"donationamount":"15000","threshold":"10000","donorsecret":"12345","badgetier":"2"}' http://localhost:3001/api/generate-proof
```

## Notes

- Inputs must respect circuit thresholds (Bronze ≥ 1000, Silver ≥ 10000, Gold ≥ 100000) or Noir will fail.
- `calldata.txt` can be excluded from the repo if preferred; keeping it helps reproducible demos.
